# ⚡ Calculadora de Stranded Capacity (Modelo de Estimación)

[![Streamlit App](https://static.streamlit.io/badges/streamlit_badge_black_white.svg)](https://share.streamlit.io/) 

## 📌 Descripción del Proyecto
Este repositorio contiene el prototipo (MVP) y la presentación ejecutiva del modelo de estimación de **Stranded Capacity** para Data Centers de IA. La herramienta permite a los operadores calcular y visualizar el impacto financiero de la desalineación entre las capas físicas (enfriamiento) y operativas de sus instalaciones.

El proyecto está desarrollado en Python utilizando **Streamlit** para la interfaz interactiva, aplicando principios de *Clean Architecture* para separar el motor de cálculo matemático (backend) de la visualización (frontend).
